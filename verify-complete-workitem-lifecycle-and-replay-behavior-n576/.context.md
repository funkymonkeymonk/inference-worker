# Goal
Verify the complete WorkItem lifecycle across success, failure, cancellation, review, merge, and restart.

# Scope
- Integration and replay coverage for the WorkItemWorkflow and its Activities.

# Implementation
Use deterministic workflow tests and a real Temporal worker where required. Do not replace missing lifecycle implementation with test-only shortcuts.

# Acceptance Criteria
- All lifecycle terminal outcomes have focused tests.
- Workflow replay remains deterministic.
- Worker restart resumes a long-running WorkItem without losing phase state.

# Tests
- Run WorkItem unit, workflow, integration, and build checks.

# Dependencies
- All WorkItem lifecycle implementation children.

# Non-Goals
- Nix service packaging.
