# Goal
Coordinate the completed worker and Nix integration after focused implementation children are terminal.

# Scope
- Review worker registration, runtime configuration, devenv, Nix packaging, launchd behavior, and end-to-end verification.

# Implementation
This is a coordination yak, not an implementation task. Its children own focused changes. Unblock this yak only after the implementation children are terminal, then run the complete verification checklist from the parent integration specification.

# Acceptance Criteria
- All focused worker, runtime, Nix, and verification children are terminal.
- The configured worker registers direct inference, WorkItemWorkflow, and WorkDispatcherWorkflow.
- Runtime and launchd configuration pass their focused tests and Nix evaluation.
- End-to-end dispatch, completion, release, and restart behavior is verified.

# Tests
- Run npm test.
- Run npm run build.
- Run the documented integration and Nix checks.

# Dependencies
- Focused implementation children below this yak.

# Non-Goals
- Do not implement production behavior directly in this coordinator yak.
