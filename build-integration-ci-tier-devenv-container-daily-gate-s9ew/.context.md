# Goal
Run the Temporal-backed integration and worker-integration suites in CI via a devenv container, on PR (advisory) and daily-when-main-changed.

# Scope
- devenv.nix: add the yx binary (mattwynne/yaks v0.2.0, public Rust source; the local copy comes from a private overlay so it must be declared in-repo) and a "ci" container (node, git, jujutsu, temporal-cli, yx, tempo; services.temporal on :7233 with namespaces inference + integration-inference).
- .github/workflows/integration.yml:
  - PR trigger: build + run the container (Temporal service starts), docker exec the integration suite; advisory (not required).
  - Daily cron: gate step compares current main SHA to inference-worker-ci-state state.json; skip if unchanged; on success update the marker.
- The integration tests are self-contained: mock inference endpoints, isolated YX_ROOT yx store, no real LLM/Bifrost or GitHub token.

# Acceptance Criteria
- [ ] devenv container builds on x86_64-linux with the Temporal service and required namespaces.
- [ ] npm run test:integration (5 tests) and the worker integration (2 tests) pass inside the container.
- [ ] PR runs are advisory (non-blocking); the unit tier remains the only required gate.
- [ ] Daily run executes only when main advanced since the last successful run; the marker is updated.

# Files
- devenv.nix
- .github/workflows/integration.yml
- inference-worker-ci-state (state.json)

# Dependencies
- Unit tier and ruleset (parent yak).

# Non-Goals
- Real LLM/Bifrost in CI; production deployment.
