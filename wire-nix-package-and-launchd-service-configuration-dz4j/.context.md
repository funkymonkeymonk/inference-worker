# Goal
Expose the configured worker as a reproducible Nix package and launchd service.

# Scope
- `flake.nix` and `nix/module.nix`.
- Package wrappers, PATH tools, explicit HOME, secrets, launchd user, working directory, keep-alive, and separate logs.

# Implementation
Keep service configuration outside workflow inputs. Supply node, git, jj, and yx through PATH and preserve the configured backend boundary.

# Acceptance Criteria
- The package builds and starts the worker wrapper.
- The module wires all required environment and secret settings.
- Launchd uses the configured user, working directory, keep-alive, and separate logs.
- Unknown backends fail during evaluation or startup.

# Tests
- Run Nix evaluation and package checks.
- Run `npm run build`.

# Dependencies
- Worker startup validation and devenv runtime configuration.

# Non-Goals
- New task backends.
- Changes to inference protocol or workflow orchestration.
