# Goal
Expose direct inference and task workflows through one configured worker process and Darwin service.

# Scope
- Wire runtime configuration, worker registration, package wrapper tools, launchd behavior, environment variables, secret references, repository remote discovery, and backend validation.
- Keep one configured backend adapter and one singleton dispatcher per repository.

# Implementation
Preserve the minimal service configuration from docs/plans/2026-09-05-task-dispatch-design.md. Supply node, git, jj, and yx through PATH; do not encode tool paths or model settings as environment variables. Keep task-tool rules in the adapter and workflow side effects in Activities.

# Acceptance Criteria
- [ ] One worker registers direct inference, WorkItemWorkflow, and WorkDispatcherWorkflow.
- [ ] Configuration supports repository root, task backend, dispatcher interval and capacity, Temporal settings, endpoint, optional API key, GitHub token, and explicit HOME.
- [ ] Unknown task backends fail clearly.
- [ ] Launchd uses explicit user, working directory, keep-alive behavior, and separate logs.
- [ ] The service starts the root-owned dispatcher without duplicating it.

# Tests
- Test worker registration and configuration.
- Evaluate the Nix package and module with defaults, backend selection, environment wiring, secret references, and launchd settings.
- Run `npm test`, `npm run build`, and repository Nix evaluation/build checks.

# Dependencies
- Backend contract and yx adapter.
- Agent Activity.
- WorkItemWorkflow and WorkDispatcherWorkflow.

# Non-Goals
- Adding a second backend.
- Changing inference endpoint semantics.
- Changing the root/descendant yak dispatch model.
