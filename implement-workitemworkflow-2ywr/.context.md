# Goal
Coordinate focused implementation of the backend-neutral work-item lifecycle.

# Scope
- Agent execution and failure release.
- Workspace, pull request, review, merge, completion, cancellation, and wont-do phases.
- Query state and lifecycle tests.

# Implementation
Implementation belongs in children below this yak. Keep workflow code deterministic and put filesystem, network, and task-tool effects in Activities.

# Acceptance Criteria
- Each lifecycle child reaches its stated terminal outcome.
- Failures, cancellation, and release preserve durable phase state.
- Review and completion state is queryable and replay-safe.

# Tests
- Run focused WorkItemWorkflow and Activity tests.
- Run npm test and npm run build.

# Dependencies
- Backend-neutral contracts.
- ExecuteAgent Activity.
- yx task backend adapter.

# Non-Goals
- Dispatcher admission.
- Nix or worker registration.
