# Goal
Make one WorkItemWorkflow claim, run the agent, and release cleanly on failure or cancellation.

# Scope
- `src/workflows/work-item.ts` and lifecycle Activities required for claim, release, cleanup, and query state.

# Implementation
Keep orchestration deterministic. Put backend, workspace, filesystem, and process effects in Activities.

# Acceptance Criteria
- Agent success reaches the documented terminal phase.
- Agent failure records durable failed state and releases the backend task.
- Cancellation and wont-do release the task and clean up Activity-owned resources.
- Query state exposes task ID, phase, workspace, feedback round, and failure reason.

# Tests
- Add focused WorkItemWorkflow and Activity tests.
- Run `npx tsx --test src/workflows/work-item.test.ts` and `npm run build`.

# Dependencies
- ExecuteAgent Activity.
- yx task backend adapter.

# Non-Goals
- Pull request review and merge lifecycle.
