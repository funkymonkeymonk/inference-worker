# Goal
Implement draft pull request, review feedback, merge, completion, and closed-unmerged handling.

# Scope
- Pull request and review Activities.
- Durable review state, feedback rounds, merge attachment, completion, and release paths.

# Implementation
Use short polling Activities and Temporal timers. Keep provider-specific behavior in Activities or the backend adapter.

# Acceptance Criteria
- Draft PR and review state are queryable.
- Review feedback persists and creates a review candidate.
- Merge attaches the PR and marks the backend task done.
- Closed-unmerged and cancellation paths release and clean up.

# Tests
- Add lifecycle Activity and workflow tests for review, merge, completion, and closed PR paths.
- Run focused tests and `npm run build`.

# Dependencies
- WorkItem agent failure and release lifecycle.

# Non-Goals
- Dispatcher admission or new task backends.
