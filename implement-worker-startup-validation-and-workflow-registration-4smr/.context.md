# Goal
Validate process configuration and register all worker workflows and Activities from one worker process.

# Scope
- `src/worker.ts` and focused worker tests.
- Temporal address, namespace, task queue, repository, endpoint, backend, dispatcher, and capacity validation.
- Registration of direct inference, WorkItemWorkflow, WorkDispatcherWorkflow, and Activities.

# Implementation
Keep process configuration outside workflows. Fail clearly for missing or unsupported settings. Preserve the stable repository-specific dispatcher ID.

# Acceptance Criteria
- Worker startup rejects invalid required configuration with actionable errors.
- All three workflows and their Activities are registered on the configured task queue.
- The dispatcher starts once and uses the stable repository-specific ID.
- Focused worker tests and `npm run build` pass.

# Tests
- Add or update worker startup tests.
- Run the focused worker tests and `npm run build`.

# Dependencies
- Backend-neutral contracts.
- WorkDispatcherWorkflow and WorkItemWorkflow interfaces.

# Non-Goals
- Nix or launchd configuration.
- New task backends.
- Inference protocol changes.
