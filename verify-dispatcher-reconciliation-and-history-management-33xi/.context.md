# Goal
Verify dispatcher polling, reconciliation, duplicate handling, and history compaction.

# Scope
- Dispatcher workflow tests for polling, capacity zero, stable duplicate IDs, replay, and continue-as-new.

# Implementation
Use deterministic workflow tests and fake backend Activities. Do not add production behavior unless a failing test identifies it.

# Acceptance Criteria
- Active, completed, and failed state is reconciled correctly.
- Capacity zero and duplicate stable IDs are safe.
- Continue-as-new compacts state without losing active work.

# Tests
- Run the focused dispatcher workflow tests and `npm run build`.

# Dependencies
- Dispatcher admission and failure handling child yak.

# Non-Goals
- Backend-specific candidate ordering.
