# Goal
Run the coding agent inside one cancellable Temporal Activity using the configured OpenAI-compatible inference endpoint.

# Scope
- Implement the typed AgentPolicy and allowed tool registry.
- Support read, write, edit, and bounded bash tools.
- Support streaming tool-call continuation, heartbeats, cancellation, timeout, and compact results.

# Implementation
Keep model calls and tool execution in the Activity. Enforce the tool allowlist and shell bounds at the Activity boundary. Do not write token chunks into Temporal history and do not add automatic retries for workspace mutations. Follow docs/plans/2026-09-05-task-dispatch-design.md.

# Acceptance Criteria
- [ ] Streaming tool calls execute allowed tools and continue until completion.
- [ ] Disallowed tools, unsafe commands, cancellation, timeout, and endpoint failures terminate predictably.
- [ ] Heartbeats occur during model calls and tool execution.
- [ ] Cancellation cleans up Activity-owned resources.
- [ ] Temporal history contains only the compact structured result.

# Tests
- Test tool allowlisting, read/write/edit behavior, bounded bash, streaming continuation, heartbeats, cancellation, timeout, API keys, and retry options.
- Run `npm test` and `npm run build`.

# Dependencies
- Backend-neutral workflow and Activity contracts.
- Existing inference endpoint configuration.

# Non-Goals
- Pi or LiteLLM compatibility.
- Per-repository agent policy.
- Arbitrary shell access.
- Automatic agent retries.
