# Goal
Admit ordered work items into available slots and record terminal failures without retry loops.

# Scope
- `src/workflows/dispatcher.ts`.
- Capacity, active state, stable child workflow IDs, child retry policy, failure reasons, and backend failure Activities.

# Implementation
Use only backend-neutral Activities and Temporal primitives. Let the backend own task blocking and failure-history mutations.

# Acceptance Criteria
- The first backend candidate is admitted when capacity is available.
- Failed children reach one controlled failure path and do not retry indefinitely.
- The dispatcher records the underlying failure reason and continues scanning independent candidates.
- Stable workflow IDs and active-task state remain deterministic across replay.

# Tests
- Add focused dispatcher failure and capacity tests.
- Run `npx tsx --test src/workflows/dispatcher.test.ts`.

# Dependencies
- WorkItemWorkflow and backend failure contract.

# Non-Goals
- Priority parsing.
- Nix or worker startup configuration.
