# Goal
Expose the direct and task workflows through one configured worker process and Darwin service, then verify the complete task-dispatch design end to end.

# Scope
- Integrate worker registration, runtime configuration, package and launchd behavior.
- Run and close cross-component unit, workflow, integration, build, and Nix evaluation checks.
- Document exact local and CI verification commands.

# Implementation
Keep implementation work in child yaks. This yak coordinates their completion and records only verification gaps required by docs/plans/2026-09-05-task-dispatch-design.md. Do not add production behavior merely to make verification pass.

# Acceptance Criteria
- [ ] Required backend, dispatcher, work-item, agent, and Nix tests exist and pass.
- [ ] `npm test` and `npm run build` pass.
- [ ] Nix package and Darwin module evaluation/build checks pass with the yx backend selected.
- [ ] A local Temporal integration run demonstrates dispatch, implementation, completion/release, and worker restart behavior.
- [ ] No test depends on an in-memory queue or backend-specific logic in workflow code.

# Tests
- Run `npm test`.
- Run `npm run build`.
- Run integration tests for dispatcher and work-item lifecycle.
- Run Nix package/module evaluation and build checks.
- Run the documented end-to-end local verification command.

# Dependencies
- All implementation child yaks below this yak.

# Non-Goals
- Performance benchmarking.
- Multiple backends.
- Production deployment.
- Stacked pull-request support.
