# Goal
Make the devenv worker process start reliably with Temporal and the local Bifrost endpoint.

# Scope
- `devenv.nix` worker process and focused runtime tasks.
- Temporal readiness, Bifrost endpoint defaults, environment overrides, and process restart behavior.

# Implementation
Keep local defaults overridable through environment variables. Do not duplicate worker configuration in application code.

# Acceptance Criteria
- The worker waits for Temporal readiness before starting.
- Local Bifrost defaults to `http://127.0.0.1:8081/v1`.
- Explicit endpoint and Temporal environment overrides remain effective.
- A worker restart does not produce a Temporal connection-close error.

# Tests
- Evaluate the devenv process configuration.
- Run the worker restart smoke check and `npm run build`.

# Dependencies
- Worker startup validation and shutdown behavior.

# Non-Goals
- Nix launchd packaging.
- Agent prompt or model behavior.
